Author

Mohamed Gharbia

Published

November 20, 2026

The archives the past era reads, with what each shows and the terms it comes under. They are kept in a separate workspace and never mixed with the present sources. Each value built from them keeps its own source date, since the represented period, c1927, is still provisional.

Access and reuse check (24 November 2026)

The STM archival-inventory PDF linked above currently returns 404; its catalogue description remains discoverable, but a working replacement file has not been verified. The 1931 census page is accessible. Four Montréal historical map/aerial datasets retain CC BY-NC-SA 4.0 in their live catalogue records. BAnQ items with unevaluated or unstated rights remain unresolved; no blanket reuse clearance is inferred. See the source reuse check.
